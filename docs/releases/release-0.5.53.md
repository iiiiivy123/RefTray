- 小红书静态正文图片优先请求同一图片的高清 PNG，保留网站提供的网页图作备用。高清源无法下载或超过单图限制时明确提示；不把旧文件转换成 PNG、不覆盖已有素材。来源记录分别保存页面图片地址、实际下载地址及画质结果。GIF、LIVE、评论图片沿用原流程。
- Pinterest 优先同一图片的 originals，ArtStation 优先 8k、4k；保留真实文件格式，不放大图片。花瓣从当前主图取得同一资源的大图候选，通过浏览器保留其有效签名和会话，失败用网页图。默认取最高可取得源，弹窗不新增清晰度选择。
- 图文未开启评论或 OCR 时省掉空章节；没有提示就不生成“采集提示”。OCR 无文字、识别失败分开表述，保留已有识别内容和用户改过的文稿。
- 预扫描从已确认的视频稿件身份计数，无需等到下载地址解析成功；提示精简为“已识别：图片 1 · 视频 1”等。
- 设置页加宽侧栏、调整主要文字与辅助信息字号，去掉重复标题和多余说明。数字单位放在输入框外，不再压住上下按钮。目录示例与新保存结构一致，“还原未保存选择”明确只撤销未保存的选择。
- 更改保存位置时，核对已手动搬到新根目录的文件，校验一致后更新采集记录与缓存地址；不会移动文件。核对有时间上限，未完成或内容不一致会提示，可通过采集记录的旧目录导入继续关联。未完成任务保留原地址。
- 纯文字来源索引随素材保存到共用的“_来源记录”目录，移动整个素材库后继续使用原文件名；旧版纯文字可由校验过的采集记录找回文件名。手动编辑过的文稿仍保留。
- 花瓣画板等待当前列表卡片加载；新作品标签页网址暂时为空时继续等待，保留画板成员和作品编号校验。修正网页刚好加载完成时遗漏完成通知的竞态。
- MCP 优先复用已加载的同一花瓣画板。图片模式可直接保存画板中带相同作品编号、且已取到原图的图片；原图不可用、身份不明或需要正文/视频/评论时仍读作品页，不以卡片缩略图代替。
- 花瓣图片卡片兼容未带详情图片标记的布局，仍核对卡片所属画板、作品编号和唯一主图；头像、其他作品和视频卡片不混入。批量可读取已经打开的同一作品，不跳转或关闭这些网页；需要新开作品时留在画板所在窗口。MCP 单篇优先使用已加载且未暂停的同一页面。
- 花瓣、Pinterest、ArtStation 正文就绪后无需等待无关资源全部完成。ArtStation 会等待作品图片出现，并明确返回读取失败原因；空结果不会当作有效作品提交。登录跳转和其他作品仍阻止采集。
- 花瓣按卡片的作品归属识别主图，兼容当前画板样式与站内详情弹层。无法从卡片取得原图时打开对应详情，读完返回画板；用户中途切换页面会停止，不抢回页面。带 `/small/` 的缩略图不盲改地址或签名。
- 修正花瓣后退后再打开下一篇时误停：按具体的上一页核对返回位置，不依赖历史记录总数增加。
- 花瓣画板同时识别“普通采集”和“素材采集”图片卡片，保留同一画板、同一作品及唯一主图的校验。
- Pinterest 单篇静态图片遇到网页首次打开超时，改用已有公开原图读取器；仍核对同一 Pin 的完整静态图片，不把分享封面冒充整篇作品。图文、评论和视频保留原流程。

## 手动搬素材库

1. 先完成或停止正在采集的任务。
2. 将图片、图文、视频、批量等素材目录一起搬到新根目录，保留各处“_来源记录”，目录层级不变。
3. 如果原素材库里的 `data` 文件夹存放设置和采集记录，请留在原处；设置页会对这种安装方式显示提示。程序状态位置与素材保存位置分开管理。
4. 在“素材库位置”选择新的根目录。已搬且内容一致的记录会关联到新位置，继续采集会复用原作品目录。

切换目录分类只影响新作品；同一素材库中已有作品按来源标记继续使用原目录。改成一个空目录会建立新的素材位置，不自动搬旧文件。

高清源规则核对参考：[XHS-Downloader 图片提取器](https://github.com/JoeanAmier/XHS-Downloader/blob/dfad51b3d1aac55866802007544f9390ad21553f/source/application/image.py)。RefTray 独立实现了窄范围图片身份转换，复用既有公共网络地址、完整字节及图片解码检查；真实样例与验证状态见 CURRENT/TASK。
