# 0.5.49 候选版：一键更新与收藏列表

此版尚未发布。首次启用更新器需要用完整安装包覆盖安装一次，此后可在“工具与帮助 → 程序更新”检查正式新版、下载并更新，也可让 AI 通过 MCP 发起更新。不会自动安装预发布版或在后台安排定时升级。当前实际安装与现场测试进度见 CURRENT.md。

- 一键更新：只从项目官方正式 Release 获取安装包，校验大小与 SHA256；有采集任务时拒绝安装。旧后台退出后备份设置和 SQLite 记录，再使用原安装器升级，核对受管文件并重启。界面显示进度；更新完成后扩展最多自动刷新一次。MCP 宿主若持有旧连接，仍需重新连接。
- MCP：新增检查更新、安装更新、查询更新结果三个工具，与界面共用更新服务。完整包一并更新 MCP 程序及运行时，重连沿用原配置路径；结果与备份位置持久保存。安装已接管时丢失回执，保留安装进程写入的结果。
- 花瓣：支持新版画板的非链接卡片以及 `/discovery/boards/…` 入口，按画板编号与作品编号核对归属，排除推荐区。普通详情等待带当前作品编号的主图加载，失败给明确提示；全屏大图和签名图片地址保留原路径。
- 小红书：支持 `/board/…` 具体收藏夹及其笔记卡片，沿用原有低频逐篇采集、跳过、暂停、续采和去重。收藏夹名称作为列表归属，不冒充笔记作者；栏目或收藏夹切换时停止并保留断点。原作者主页和个人收藏列表继续支持。
- UI：沿用暖灰、细线样式，整理弹窗选项和设置页对齐；修复视频批量“跳过前几篇/集”输入未生效。
