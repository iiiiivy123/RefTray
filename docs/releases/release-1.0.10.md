# RefTray 1.0.10 · 悬浮类型提示与预识别修复

修复视频页悬浮面板显示“图文笔记”、但实际保存视频的不一致，并补齐全部已适配平台的预识别与错误传播回归。

## 本次修复

- 明确的B站、YouTube视频页显示“视频页”及实际悬浮保存方式，默认仅视频含原声音。其余未扫描的页面显示“点击保存时识别内容”，不再把默认图文偏好冒充识别结果。
- 小红书、Instagram的视频源尚未加载、媒体解析失败，以及Pinterest动态内容未就绪时，明确提示重试，不自动退回保存封面或文字。
- GIF与Live Photo不再额外计成未知视频，混合图文仍保留原附件设置。
- 修复Instagram含用户名作品地址的入口识别、悬停旧提示残留和错误原因丢失，更新引导中的拖动说明。

## 如何更新

点Chrome工具栏的RefTray图标，打开采集弹窗；空闲时发现正式新版会显示更新提醒，点击“下载并更新”开始安装。自动检查成功后缓存一天，提醒选择“稍后”也会延后一天。

想立即检查，请进入 **设置 → 关于与更新 → 检查更新 → 下载并更新**，或从Windows托盘选择“程序更新”。程序不会定时自动安装。更新完成后刷新作品网页；若扩展仍显示旧版，在`chrome://extensions`重新加载RefTray。

也可从[本次发布](https://github.com/iiiiivy123/RefTray/releases/tag/v1.0.10)下载完整Windows安装包，覆盖原程序目录。素材、设置和采集记录保留。更新说明见[更新指南](../update.md)。
