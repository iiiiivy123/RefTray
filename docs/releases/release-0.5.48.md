# 0.5.48 预发布版 · MCP 后台采集与 B 站选集

这版把 MCP 接单移到 Chrome 扩展后台。Chrome 和 RefTray 保持运行即可，采集弹窗可以关闭。

- 自动打开或复用目标作品页，后台执行并返回进度、结果与保存目录。
- 采集可指定图文、评论、楼中楼、GIF、OCR、视频、字幕、音频、抽帧、裁切和本次目录；未指定的选项采用设置默认值。
- 新增作者、画板和播放列表批量入口，复用扩展各平台的批量流程。
- B 站视频页可直接批量保存分 P 选集，支持视频、音频及跳过前几集；按选集编号分别命名。
- X 同帖多个已识别视频顺序保存，也可指定第几个。
- 新增任务暂停、继续、停止、失败重试、任务列表、保存记录搜索和按任务查看诊断。
- 新增本地视频转 GIF、提取音频入口。
- 视频解析改为短请求查询，Chrome 不必一直等待一个长请求返回。
- 修复部分 B 站视频和音频因首选地址使用特殊端口而下载失败；使用同一轨道提供的常规备用地址。
- 补齐 B 站网页单文件视频的备用地址选择；B 站、X 和 Instagram 先检查候选地址，再按画质选择，避免一个无效地址挡住其他可用媒体。
- 修复预扫描沿用上次参数、重复解析占用，以及画质和字幕选项改变后仍使用旧解析结果的问题。
- 解析过程支持停止；退出后台时一并结束解析。MCP 进度按当前任务更新，避免显示上一项任务的进度。
- 整理媒体地址规则和视频顺序保存模块，减少解析、下载与接单之间的交叉依赖。

使用方法见 [MCP 说明](../mcp.md)。Chrome 最低版本为 120。更新后重新加载扩展，并刷新 AI 客户端的 MCP 连接。

原有图片、GIF、小红书批量和手动弹窗流程继续保留。229 项自动化检查通过；包内 MCP 调用、图文文件和本地加工已检查，用户提供的 B 站第 3 P 已实际保存为音频。

请重点试：关闭弹窗后的 MCP 采集、任务暂停和继续、B 站视频页分 P 批量。X 登录视频、花瓣全屏图和批量也需要继续实测。
