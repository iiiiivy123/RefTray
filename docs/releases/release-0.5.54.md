# RefTray 0.5.54 候选版

- X 作者主页批量兼容普通视频播放器的跟踪容器，不再把正常视频帖全部过滤。列表识别失败按实际原因提示，不再误报未登录。长视频卡片仍可向下滚动或列表正在加载时继续扫描；已确认的作品标题不会被刚打开的标签页空标题覆盖。
- X 作者批量从前台列表顺序读取；切到后台时等待恢复，超时保留断点，不继续滚过尚未显示的作品。作品标题优先采用对应帖子卡片的正文。
- 管理页工具名称只显示一次，下载确认只放在任务页。诊断记录有独立侧栏入口，每页 10 条，详细日志默认折叠。
- 更新入口移到“设置 → 关于与更新”，右下角托盘“程序更新”打开同一页。现有更新与恢复流程继续使用，素材、设置和记录保留。
- 软件内使用说明改成离线排版页面，纯文本说明不再直接塞入 Markdown 标记；GitHub 首页改用简洁的标准 Markdown。

当前为正式版前候选，未公开发布为 1.0。实际安装与采集验证见开发交接记录。
