# RefTray 1.0.9 候选 · 默认纯视频与独立悬浮设置

这一版整合此前的本地候选，补充悬浮保存进度和小红书音轨检查。新增独立悬浮默认设置，视频默认不额外提取字幕。尚未公开发布。

## 主要变化

- 设置页新增“悬浮保存”分类，默认仅保存原视频和声音；可改为视频＋字幕/文字稿、仅文字稿、仅音频或抽帧。只影响下一次悬浮保存，原素材、普通采集偏好和已开始任务保持。
- 新视频任务未指定字幕时不再自动提取字幕或生成文字稿；弹窗保留用户显式选择。原视频画面中已有的字幕不删除。

- 下载时按钮显示真实百分比，悬停或再次点击查看已下载大小、总大小、实测速度和停止按钮；识别、连接、合并/整理及写入记录分别显示。未知总大小不编百分比，长时间没有进展会提示等待响应。
- 停止仅作用于当前页面的这一次保存，已保存文件保留；忙碌时重复点击不创建第二个任务。
- 小红书优先选择包含声音的视频源，保存后核对音轨。明确带声音的源若下载结果缺音轨会失败；未知无声音源报告部分完成，旧无声缓存不再当作完整视频复用。

- 悬浮保存采用深色按钮和米白小面板。点击直接保存；拖动只移动，并记住位置；没有旧位置时默认显示在右上方。
- 所有已适配的单篇采集入口先识别当前内容，再决定保存视频、图片/GIF或正文。视频主帖不会被图文的“跳过视频附件”设置跳过；明确选择仅正文时仍保留该偏好。
- 悬停打开“本次保存选项”和最近保存文件夹；临时选择仅作用于该次任务。结果简短，失败可重试和查看详情。
- 新装先确认素材库，默认在 RefTray 下创建“素材库”，也可更改；旧用户显示当前路径，保留旧素材与设置。
- 首次引导按打开扩展管理、打开扩展目录、检查连接逐步进行。
- 整页长截图进入扩展的“采集内容”下拉菜单，保存 PNG、原网址说明及记录。SVG 直链和已适配 SVGLOGO 内容保留矢量格式。
- B站作者列表等待加载后再读取，复用已经验证的页面；未识别投稿列表时明确失败，不退回抓取广告和推荐。

## 下载和更新

Windows 10/11 x64、Chrome 120 或更新版本。候选尚未公开；正式发布后安装包会列在 [Releases](https://github.com/iiiiivy123/RefTray/releases)。普通用户无需另装 Python 或 FFmpeg。

覆盖安装到原程序目录，素材和设置保留。完成后在 `chrome://extensions` 重新加载 RefTray，再刷新作品页；使用 MCP 的客户端需重新连接。软件内更新与恢复步骤见[更新说明](../update.md)。

`user.zip` 是需要自行配置运行环境的源码运行包；GitHub 的 Source code 包面向开发者。

## 验证和范围

1.0.8已完成本机升级保留检查及真实小红书悬浮保存：进度数字变化，文件有画面及AAC声音，文件摘要与历史记录相符。1.0.9新增默认设置的回归、构建与安装验收记录随后补齐。此前B站及ArtStation预识别通过，不能代替各站完整下载验收。所有单篇入口共用预识别，不代表任何网站或未适配页面都能采集。网站访问限制、页面变化、未加载内容会明确报告。

SVG只支持可直接获取且校验通过的源文件；长截图不会展开折叠区域、内部独立滚动区或视频动画，超限页面明确停止。B站电影/番剧完整下载尚未支持，不将试看当作整片。干净Windows的完整首次安装/卸载和登录自启验收尚未完成。
