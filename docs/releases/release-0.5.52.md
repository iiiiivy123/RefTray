# RefTray 0.5.52

新采集使用已确认的保存目录方案。单篇按“图片-标题 / 图文-标题 / 视频-标题 / 音频-标题”命名；批量先按主页、收藏夹、画板、合集或分P分组，再按作品保存，去掉原先重复的作者、笔记、视频等中间层。

B站单篇图文和专栏一直有采集入口，本次补齐目录说明：`图文/B站/图文-标题`。分P使用 `批量/B站/分P采集-总标题-UP主/P03-分P标题`。小红书收藏夹与作者主页放在同一级。

Pinterest 单图、Pinterest / 花瓣画板图片继续平铺；纯文字直接保存为 MD。不会预建用不到的四个分类文件夹；没有成功保存内容时，不保留本次产生的空作品目录。已有空文件夹不自动清理。

旧素材不移动、不改名；未完成的旧任务继续使用原目录。同一作品重新发起新任务时采用新规则，新规则内重复采集会复用已有目录并保留用户改过的文字稿。

更新包含后台、Chrome 扩展和 MCP 文件。Chrome 提示版本不一致时重新加载 RefTray；已打开的 AI 客户端在重新连接 MCP 后加载新版接口。详细路径见[保存目录说明](../development/archive/SAVE-LAYOUT-REVIEW-2026-11-11.md)。
