# RefTray 0.5.47 · 预发布版

本版汇总近期功能和试用反馈修复。

## 新版功能

- 视频保存内容统一为下拉选择：视频 + 字幕 + MD、仅视频、仅文字稿、仅提取音频。自动抽帧另选，默认间隔 1 秒。
- 图片与图文直接显示跳过视频、跳过 GIF；评论分别设置一级评论数量和每层回复数量。
- 去重方式、下载上限和抽帧间隔移到设置页。管理页采用细线分区，清理重复说明。
- 失败任务可直接打开对应媒体诊断，支持搜索和分类。
- MCP 加入 Chrome 页面采集、整帖视频顺序下载和停止队列；可按作品链接查询已有文件。
- 弹窗检查正式新版并提醒。更新需手动下载安装包。

## 针对实际反馈的修复

- 修复 0.5.44 恢复旧任务时导致的后台启动失败。
- 调整 X 页面媒体读取、图片 / GIF 分类和批量遇到纯文字帖时的计数。
- 补充花瓣详情页主图识别和浏览器读取。
- 更新时处理旧后台及本程序 MCP 的占用，并同步已登记的扩展目录。

## 还没验完

X 登录视频的实际下载、花瓣全屏图片与批量、全平台线上回归，以及干净 Windows 机器的安装。花瓣和 X 的这些反馈仍保留为待办。

## 已检查

采集 JavaScript 检查、74 项采集后台测试和 35 项构建安装测试通过。安装包 1,794 个文件校验通过，本机覆盖安装、后台启动和新版 MCP 状态查询成功。

## 安装与更新

从本版本 Assets 下载 `InspirationCollector-0.5.47-Windows-x64-Setup.exe`，安装到原目录。完成后重新加载 Chrome 扩展、刷新作品页；使用 MCP 时刷新 AI 客户端连接。

素材库与设置保留。详细步骤见仓库中的 `docs/update.md`；已反馈问题见 `docs/use-cases.md`。
