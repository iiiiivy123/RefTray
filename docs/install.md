# 首次安装

需要 Windows 10/11 64 位和 Chrome 120 或更新版本。当前正式版为 **1.0.1**。

## 1. 下载安装包

打开 [Releases 下载页](https://github.com/iiiiivy123/RefTray/releases)，在 Assets 下载文件名以 `Windows-x64-Setup.exe` 结尾的安装包，以及同版本的 `SHA256SUMS` 文件。`user.zip` 和 Source code ZIP 都需要自行配置运行环境；普通使用请选择安装包。

安装包内置运行环境、媒体组件和扩展文件。

AI客户端接入见 [MCP接口](mcp.md)。本地视频抽帧、视频转GIF和音频提取位于管理页“工具与帮助”。

安装包尚未签名。下载后，在文件所在文件夹打开 PowerShell，运行：

```powershell
Get-FileHash .\InspirationCollector-1.0.1-Windows-x64-Setup.exe -Algorithm SHA256
```

把输出的 Hash 与 `SHA256SUMS-1.0.1.txt` 中该文件名旁的值对照，字母大小写不影响比较。不一致就先别运行，重新从本仓库下载。SHA256 一致只说明下载文件与发布的校验值相符，不是安全认证。Windows SmartScreen 若提示未知发布者，先核实下载来源和校验结果；不要关闭系统安全防护。不确定时先停止安装，并附提示截图反馈。

## 2. 安装并启动

双击安装包，按向导完成安装。默认安装到当前用户目录，无需管理员权限。

打开桌面或开始菜单中的 **灵感采集**，在 Windows 右下角系统托盘找到它的图标；图标可能藏在向上的小箭头里。程序在后台运行，没有单独的主窗口。设置和采集操作都在 Chrome 扩展里。

采集时保持后台运行。需要退出时，在托盘图标上右键选择 **退出灵感采集**。关闭 Chrome 或扩展弹窗后，后台仍会运行。

## 3. 把扩展添加到 Chrome

1. 右键托盘图标，选择 **复制扩展文件夹地址**。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角 **开发者模式**，点击 **加载已解压的扩展程序**（有些版本叫“加载未打包的扩展程序”）。
4. 在文件夹选择窗口按 **Ctrl+L → Ctrl+V → 回车**，再点击 **选择文件夹**。选中的是 `extension` 文件夹，里面应有 `manifest.json`。
5. Chrome 出现“灵感采集”扩展卡片后，在工具栏的拼图菜单中将它固定。

扩展目前需要手动加载。安装位置可以自定义，**请使用托盘复制出的实际地址**。如果文件夹不存在，先确认安装已完成、当前启动的是新安装的程序；不要照抄别人的目录。

## 4. 选择素材库

打开扩展，点击右上角设置，选择一个可写、空间充足的文件夹。所有新任务默认保存到这里。文件夹名称由你决定，教程中的目录只是示例。

更改素材库位置只影响新任务，旧文件留在原处；可从采集记录打开它们。历史记录和设置由程序单独保存，无需从别人那里复制数据库或日志。

## 5. 保存第一份素材

打开一篇自己有权保存的作品，点击扩展，选择当前页面可用的内容类型，检查保存位置后开始。视频可能需要先确认下载大小。

完成后点击 **打开文件夹**，检查图片能否打开、媒体能否播放。若失败，请保留错误提示，并按下面的方法排查。

## 常见问题

- **连接不到后台**：从开始菜单启动“灵感采集”，确认托盘图标出现后，重新打开扩展。
- **版本不一致**：按 [更新说明](update.md) 重新加载扩展，再刷新作品页。
- **端口被占用**：退出自己仍在运行的旧版后台；不要结束来源不明的其他程序。
- **提示服务启动失败**：升级后失败时，先看 [更新与恢复说明](update.md)。0.5.50起会保存独立的旧程序恢复入口；启动日志默认在 `%LOCALAPPDATA%\InspirationCollector\data\inspiration\logs\service-errors.log`，自定义状态目录则看其中的同名日志。
- **花瓣图片或 X 视频保存失败**：查看 [常见问题](use-cases.md)，保留该次任务记录。

仍有问题时，反馈版本、操作步骤、错误编号和脱敏截图即可。请勿发送 Cookie、密码或完整私人日志。更多操作见 [使用教程](usage.md)。
