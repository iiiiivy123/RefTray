# 首次安装（Windows 10/11 64 位 + Chrome）

## 1. 下载哪一个文件

打开 [GitHub Releases](https://github.com/iiiiivy123/inspiration-collector/releases)，选择需要的版本，在 Assets 下载 `InspirationCollector-版本-Windows-x64-Setup.exe`。不要把 GitHub 自动生成的 Source code ZIP 当作安装包。若版本标注为预发布 / 朋友试用版，请先阅读该版本的已知限制。

安装包包含 Python、媒体组件和扩展文件，不需要安装 Python、Node 或命令行工具。YouTube 等平台可能额外要求可用的 JavaScript 运行组件；以本地「帮助与工具」检测结果和版本说明为准。

安装包目前未进行代码签名。请核实仓库、版本、SHA256 校验文件及系统安全提示；不要关闭防护或运行来源不明的副本。

## 2. 安装并启动后台

双击安装包，按向导完成安装。默认安装在当前用户目录，不需要管理员权限。启动「灵感采集」，右下角系统托盘出现图标即代表程序入口已经运行；图标可能收在向上的小箭头里。

这是 **Chrome 扩展 + 本机托盘后台**，不是另外一套桌面设置软件。关闭扩展弹窗或 Chrome 不会自动启动后台，也不等于退出后台。不要同时运行两套安装目录中的后台。

## 3. 第一次加载 Chrome 扩展

1. 在托盘图标上右键，选择「打开扩展文件夹」或「复制扩展文件夹地址」。
2. Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择安装目录下的 **extension 文件夹本身**，不是安装目录、压缩包或某个文件。
5. 在 Chrome 工具栏的拼图菜单中固定「灵感采集」。

扩展目前没有上架 Chrome 扩展商店，需要手动加载。不要加载朋友自己的 F 盘路径；每台电脑的实际安装目录不同。

## 4. 选择自己的素材库

点扩展右上角设置，选择你自己的可写文件夹，例如 `D:\参考素材`。更改位置不会自动搬迁旧文件。默认设置、历史记录等程序状态与素材文件分开保存；不要把别人导出的数据库或日志当成安装配置。

## 5. 保存第一份素材

先打开自己拥有权利或已获准保存的普通作品页，选择图片、图文、文字、视频或音频模式。检查保存位置、下载上限和任务范围后开始，遇到大小确认时按实际提示确认。

以任务状态显示完成、保存位置确实出现文件、图片可打开或媒体可播放为成功标准。网页打开、后台已连接、检查出媒体大小都不等于保存完成。失败请提供版本、错误编号、普通公开测试链接与脱敏截图；不要发 Cookie、密码或完整私人日志。

## 常见问题

- **连接不到后台**：先从开始菜单启动「灵感采集」，确认托盘图标，再关闭旧弹窗重新打开。
- **版本不一致**：参见 [更新说明](update.md)，安装后还需要重新加载扩展并刷新作品页。
- **端口被占用**：先退出自己已有的旧后台；程序不会擅自关闭其他软件。
- **平台内容打不开或解析失败**：登录、访问权限、地区、平台变化都可能影响结果。程序不绕过验证码、会员、DRM 或其他访问限制。

详细能力与本版本验收范围请阅读同一 Release 的说明，不把“已适配某平台”理解为全站全部链接保证可用。
