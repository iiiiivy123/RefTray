# RefTray 0.5.37 交付与审查说明

日期：2026-11-06。该版本包含此前尚未推送的0.5.30–0.5.36修改，以及本次管理页、评论静态配图和本地加工增量。安装包与源码分支用于本轮交付/审查，不代表所有待办均已线上验收。

## 本次变化

- 管理页中/EN按钮替代语言下拉；采集记录及任务记录每页20条。任务在后台先筛选再分页，不再因为当前页没有匹配项而漏看其他页。
- 未完成包含暂停/中断和部分失败；失败指没有成功保存内容的失败任务；忽略项仍可恢复。成功任务可在采集记录查看。修复已同步旧任务仍带localOnly标记时不读取后台详情的问题。
- 删除Chrome实测助手用户入口，媒体诊断保留一个位置。新增本地视频转GIF、提取M4A音频，原文件保留，结果另存素材库“加工结果”。文件上限512MB，GIF沿用现有120秒/20fps/最长宽640/128MB限制及组件要求；未上传云端。
- X图文评论数量默认10，设置页可保存默认值，弹窗更多可覆盖。补纯图片直接回复及评论配图关联，按当前排序读取已加载且确认父帖ID的回复。不以整页抓图替代归属校验。
- 下次安装不再出现完成后的重复“Chrome固定扩展目录”提示；原完成页选项和实际扩展目录同步仍保留。

## 保留基线

用户已确认实际0.5.36网页GIF正常，不再修改网页GIF识别/下载/转换逻辑。platforms.js（含Pinterest）、page-media.js、page-identify.js、video.py、gif_media.py、segmented_media.py与0.5.36构建输入逐字节一致。

background.js和batch.js只在本次新增评论图片分支上追加行为；共用文件并非完全不变，需审查该分支的条件与回归证据。既有代理、主帖身份核对和旧素材不变。

## 给审查者

先读AGENTS.md、docs/CURRENT.md和docs/SPEC.md。当前本机Ivy入口属于执行环境，其他宿主不可读时明确报告，不应猜测其内容。

重点审查：manage.js/catalog.py/app.py的筛选分页与本机较新记录合并；x-comments.js对父帖和纯图片回复的处理；background.js/batch.js评论分支是否影响旧媒体；storage.py评论去重及Markdown引用；local_tools.py的授权、文件上限、输出路径、停止/升级占用。不要以“清理结构”为由重写已通过的Pinterest/GIF/代理实现。

旧素材不需要搬动。安装前退出托盘程序；安装后重新加载Chrome扩展一次，再刷新作品页。安装包升级不等于Chrome已加载新代码。
