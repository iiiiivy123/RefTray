# RefTray 0.5.47（预发布）

本版汇总 0.5.42 后的修复与管理页调整，供现有用户试用。

## 更新内容
- 管理页恢复细线分隔，去掉工具、任务和诊断的嵌套外框；清理常驻说明，统一文字和操作布局。
- 诊断支持搜索、分类和失败任务定位；主帖身份错误独立归类。
- 调整 X 登录页面媒体交接、图片/GIF 分类，以及批量遇到纯文字帖时的数量处理。
- 补充花瓣详情页主图识别；调整视频输出、采集选项和任务进度。
- 修复旧任务恢复导致的启动失败及部分升级处理。

## 已检查
- JavaScript 采集回归及全扩展脚本语法检查通过。
- 74 项采集后台测试、35 项构建和安装契约测试通过。
- 离线依赖预检、1,794 个文件哈希校验、打包运行时启动与退出检查通过。
- 本机正式覆盖安装成功，后台返回 0.5.47，登记扩展目录同步成功，设置文件未变化；新版 MCP 独立状态调用成功。
- 管理页使用模拟数据在 Chrome 检查；不是平台下载验收。

## 仍待验证
- X 登录态视频从页面读取到实际下载的完整流程。
- 花瓣全屏图片及全部批量场景。
- 干净 Windows 环境安装、全平台线上回归。

## 更新
下载安装包覆盖安装。安装器会协调旧后台退出；完成后在 Chrome 扩展管理页重新加载扩展，并刷新已打开的作品页。保留原采集目录与设置。
