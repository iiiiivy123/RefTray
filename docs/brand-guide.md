# RefTray 品牌与表达规范

## 名称与定位

**英文名称：RefTray**  
**中文名称：灵感采集**  
**组合写法：RefTray · 灵感采集**  
**类别描述：Windows + Chrome 本地素材采集工具**  
**英文描述：Local-first reference and media collector**

**把网页素材，存进自己的文件夹。**  
**Your references. Your folders.**

RefTray 帮助创作者将有权保存的网页图片、图文笔记和视频参考整理到本机素材库，支持部分网站的批量采集和视频抽帧。它不是云端素材网站、创作社区、平台官方工具或通用全网爬虫。

名字短的场景只写 RefTray；中文教程和系统操作说明使用「灵感采集」，与现有程序里的名称对应。不要另造一个中文译名。旧展示名 InspiShelf 指向同一项目。

## 视觉原则

使用系统默认无衬线字体，黑白与中性灰、细分隔线、清楚的对齐和轻量留白。不要用装饰性英文标签制造层级，也不把网页插件弹窗画成手机 App。

图标不使用第三方平台标志，不用星星或魔法棒暗示内容生成。网页插图应表达「网页 → 本地目录」，不要凭空增加云同步、素材社区、笔记系统等能力。界面设计稿必须标为原型，不能充当已发布版本截图。

## 表达原则

- 先解释用户得到的文件与操作，再解释实现机制。
- 不写「全网神器」「轻松搬空」「无损破解」「永久有效」「官方认证」。
- 适合设计师、插画师、视频剪辑与内容研究，不限定单一职业。
- 当前需要 Windows 安装与 Chrome 手动加载扩展，不宣称已上架商店、有手机端或自动更新。
- 收藏夹主要保存入口；本工具在支持的页面保存实际文件，但不保证第三方网页完整或永久可访问。

## 名称、文档与二进制兼容

当前公开安装包为 v0.5.13，安装器、Windows 快捷方式、托盘与扩展仍使用「灵感采集 / Inspiration Collector」。RefTray 目前是文档和视觉展示名称；更换程序内名称、图标需单独构建、升级测试与发布。

本次不重命名仓库，不全局替换 `InspirationCollector`、`LIBLIB_ROOT`、安装器 AppId、状态目录或用户素材路径。较早的宣传稿、演示脚本等保留原文，引用时按本规范校正名称并核实功能。

名称仅做过初步公开检索，**尚未完成商标、域名与软件商店的系统性权利核验**；本文件不主张可注册性或排他性。
