# RefTray 1.0.1 使用教程

适用于 Windows + Chrome。首次使用见 [安装步骤](install.md)，从旧版升级见 [更新步骤](update.md)。

## 当前作品怎么保存

打开作品详情页，点 Chrome 工具栏里的 RefTray，选择采集内容和保存位置。

| 采集内容 | 保存什么 | 常用选项 |
| --- | --- | --- |
| 图片 / GIF | 图片与动图 | 跳过视频、跳过 GIF |
| 图文笔记 | 正文 Markdown 和正文图片 | 媒体过滤、评论、识别图片文字 |
| 纯文字 · Markdown | 正文文字 | 评论 |
| 视频 | 视频、字幕文字稿或音频 | 保存内容、画质、自动抽帧、跳过开头 / 结尾 |

图片和图文默认跳过视频。图文自带正文图片；只需要文字时选纯文字。图片文字识别用于把图中的文字补进图文笔记。

## 视频、字幕、MD 和音频

「保存内容」提供以下选择：

- **视频 + 字幕 + MD**：保存视频、字幕和文字稿；网站没有字幕时使用本地语音识别。
- **仅视频，不提取文字**：只保存视频。
- **仅文字稿（MD）**：保存文字稿。
- **仅提取音频**：保存音频。
- **仅保存封面**：B站当前视频的最后一项。选中后再点“保存封面”才执行；不下载视频。

网站提供字幕时优先使用原字幕。完整安装包内置本地语音组件；没有网站字幕时在CPU上识别，不上传视频，无需另外配置模型。长视频需要等待，结果可能有错字或繁体字，请按用途校对。识别失败时原视频保留，不生成空字幕。「自动抽帧」另行开启，默认每 1 秒一张，间隔在设置页修改。「跳过首尾」一行填写开头、结尾的秒数。

本地视频可以在管理页工具中抽帧、转 GIF 或提取 M4A 音频，结果另存。

## 评论怎么计数

在「采集选项」勾选「评论」。最多一级评论数、是否包含楼中楼、每条评论最多回复数统一在右上角设置中修改，弹窗不再重复显示。一级评论默认 10 条；楼中楼默认关闭，开启后每条默认最多 2 条回复，不占一级评论名额。小红书和 Instagram 的回复展开有数量和等待上限，不足数量会说明原因。识别图片文字也在「采集选项」这一行。

## 批量采集

打开作者主页、画板或视频列表，切到「批量采集」，选择内容类型、数量和保存位置。可以设置跳过前几篇。

B 站选集直接填写 **从第几 P 开始** 和 **数量**。例如从 P10 开始、数量 5，页面显示 P10–P14；范围超过总 P 数时在最后一 P 停止。起始 P 不自动跟随网页正在播放的 P，续采沿用原任务范围。

视频页右侧由多个独立稿件组成的合集，也可直接切到「批量采集」。这里显示 **从第几个视频开始**，按当前合集顺序保存，保留每个稿件的标题；不包含下方推荐视频。若当前稿件自身有多个 P，仍优先处理该稿件的分 P 选集。

视频地址提供了同一轨道的备用线路时，遇到下载中途断线会换线路重下当前轨道。已经完整下载的另一条音轨保留；取消、超出大小限制或收到错误内容时会停止，并显示原因。

花瓣可直接打开具体画板，包含新版推荐入口中的画板；只读取归属当前画板的作品。小红书可打开个人主页的收藏栏目，或进入具体收藏夹后批量采集；收藏夹总览需要先进入一个收藏夹。批量期间保持原列表和排序，切换列表会停止并保留已完成记录。

X 批量只采主页作者的作品；不包含转帖和引用帖。没有所选媒体的作品会跳过，再继续读取。已保存内容按设置中的去重方式处理。任务详情分别列出新增、已有、跳过和失败结果。

**X 批量期间请保持作者主页在前台。** MCP 会打开一个独立的主页标签；切到其他标签时先等待，不继续盲目滚动。等待超过约 30 秒会保留已完成记录，切回主页后可继续未完成任务。

进度圆圈显示整批进度，旁边显示当前作品的处理情况。解析和扫描时显示当前阶段；等待下载确认时先确认，再继续保存。

## 设置页放哪些参数

| 设置 | 用途 |
| --- | --- |
| 自动去重补齐 / 重新读取原帖 | 再次采集同一作品时的处理方式 |
| 下载上限 | 限制单个媒体的下载大小 |
| 默认一级评论数 | 每篇作品默认收集多少条直接评论 |
| 每条一级评论最多回复数 | 楼中楼开启后的每层回复数量，默认 2 条 |
| 最小图片宽度 | 过滤低于指定宽度的小图，单位是像素 |
| 抽帧间隔 | 两张参考画面之间的时间，默认 1 秒 |

## 找文件、重试和查原因

程序更新位于 **设置 → 关于与更新**，托盘的“程序更新”打开同一页。首次从旧版启用更新器仍需运行一次完整安装包，之后可以一键更新到正式新版，详见[更新步骤](update.md)。

完成后点「打开保存位置」。采集记录保留作品和文件位置；更改素材库位置不会搬迁旧文件。

0.5.52 起新采集按“类型-标题”命名，例如 `图文/B站/图文-标题`。批量按入口分组，例如 `批量/小红书/收藏夹采集-减肥-Ivy/图文-标题`、`批量/B站/分P采集-总标题-UP主/P03-分P标题`。图片、视频、字幕、文字稿直接放在作品目录，没有额外的“内容”文件夹。Pinterest 单图和花瓣/Pinterest画板图片继续平铺；纯文字直接保存成 MD。只创建用到的目录，失败不留下本次新建的空目录。旧素材不搬动，旧任务续采保留原位置。完整列表见[各平台保存目录](SAVE-LAYOUT-REVIEW-2026-11-11.md)。

点击保存位置先打开路径弹窗，可以直接输入完整路径，或点“选择系统文件夹”浏览目录；选好后点“使用此目录”。点取消会关闭本次系统选择窗口并保留原位置。这里仅更改本次保存位置，不修改默认素材库。

失败时打开任务详情，选择只重试失败项。带诊断编号的错误可以直接跳到对应诊断，也可以在左侧“诊断记录”搜索编号、站点或错误文字。每页显示 10 条，点“查看详细日志”展开。下载确认留在“任务”页，工具页只显示工具。

离线使用说明可从“工具与帮助”或 Windows 托盘打开，页面自带排版，无需另装阅读器。
