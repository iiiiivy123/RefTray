# RefTray · 灵感采集 使用说明 · Windows

[首次安装](https://github.com/iiiiivy123/inspiration-collector/blob/main/docs/install.md) · [从旧版更新](https://github.com/iiiiivy123/inspiration-collector/blob/main/docs/update.md)

## 0.5.37 的使用入口

- AI客户端通过 [MCP接口](mcp.md) 调用后台状态、分享图保存、视频解析/下载和任务结果。
- 管理页“工具与帮助”提供本地视频抽帧、视频转GIF、提取M4A音频，结果保存在素材库“加工结果”。
- 采集记录和任务记录每页20条，使用上一页/下一页翻页。
- 评论默认条数在设置页，当前任务可在“更多选项”覆盖。当前处理已加载直接回复的文字和静态配图。

程序、快捷方式、托盘和 Chrome 扩展继续显示「灵感采集 / Inspiration Collector」，保持安装位置与旧数据兼容。对外展示名称为 RefTray；使用用户选定的 A 款空白文件轮廓与右上方块图标。

把你有权保存的网页图片、图文笔记和视频整理到自己的电脑；可在受支持的平台和模式中批量采集作者作品或画板内容，并从视频中提取画面。平台支持范围和版权说明详见 [README](https://github.com/iiiiivy123/inspiration-collector/blob/main/README.md) 与 [版权、隐私说明](https://github.com/iiiiivy123/inspiration-collector/blob/main/docs/rights-and-privacy.md)。

**日常使用：打开灵感采集 → 打开目标网页 → 点击 Chrome 扩展 → 选择内容 → 开始采集。**

> **已有旧版、准备更新？请先退出旧后台！** 在 Windows 右下角找到「灵感采集」托盘图标（可能藏在 **∧** 内），右键选择 **退出灵感采集**，确认退出后再启动新的安装包。**关闭 Chrome 或扩展弹窗后，后台仍会运行。** 完整步骤见第 7 节「更新与卸载」。

## 1. 下载与安装

目前提供 Windows 10/11 64 位安装包，配合 Chrome 使用。安装包已内置 Python 和所需依赖，不需要自己安装或配置环境。

1. 打开 [下载页面](https://github.com/iiiiivy123/inspiration-collector/releases)。
2. 在 **Assets** 中下载 `InspirationCollector-0.5.37-Windows-x64-Setup.exe`，不要下载 Source code。
3. **如果电脑已经安装过旧版，请先按第 7 节退出正在运行的「灵感采集」后台**，再双击安装包；全新安装可直接继续。按安装向导操作。
4. 从开始菜单（或桌面快捷方式）打开 **灵感采集**。程序在后台运行，不会弹出主窗口；在 Windows 右下角系统托盘（可能收在向上的小箭头里）找到“灵感采集”。把鼠标停在图标上可查看名称。右键可打开本说明、打开或复制扩展文件夹、退出程序。

> 请下载 Windows-x64-Setup.exe，不要下载 Source code。
>
> 安装包尚未签名，Windows 可能提示未知发布者。只使用维护者提供的安装包；来源不明时不要运行，也不需要关闭杀毒软件。

## 2. 首次把扩展添加到 Chrome

这一步只需首次操作。桌面程序负责本地保存，Chrome 扩展负责读取你正在浏览的页面，两者都需要。

1. 右键 Windows 右下角的灵感采集托盘图标，点 **复制扩展文件夹地址**。这会复制实际安装位置，不要求你自己查路径。
2. 打开 Chrome，在地址栏输入 `chrome://extensions` 并回车，开启右上角 **开发者模式**，点 **加载未打包的扩展程序**（部分旧版 Chrome 称“加载已解压的扩展程序”）。
3. 会弹出系统文件夹选择窗口。在这个窗口按 **Ctrl+L → Ctrl+V → 回车**，再点 **选择文件夹**。选中的是 `extension` 文件夹本身，不是里面某个文件，也不是它的上一级。
4. 回到 Chrome，看到 **灵感采集卡片且开关已开启**，才表示加载完成。现在可以关闭这个扩展管理页面，以后不用每天重新加载。
5. 点击 Chrome 右上角 **拼图图标 → 灵感采集旁的图钉**，把它固定到工具栏。以后从工具栏的灵感采集图标打开使用；不需要回到扩展管理页面。

如果粘贴出的不是扩展地址，说明剪贴板被覆盖了；重新从托盘复制地址即可。不能加载时，检查所选文件夹内是否包含 `manifest.json`。

如果安装时没有改路径，扩展通常位于：

```text
%LOCALAPPDATA%\Programs\InspirationCollector\extension
```

安装到其他位置时，这个默认目录可能不存在；请以托盘复制的实际地址为准。已经打开的目标网页，先刷新一次再采集。

**加载完成后：**打开想保存的作品网页，点击 Chrome 工具栏的灵感采集图标。第一次先按下一节选择素材库；之后从弹窗选择内容并开始采集。桌面程序负责保存，浏览器扩展负责读取页面，两个部分都需要。关闭本说明或 Chrome 扩展管理页不会停止后台服务。

## 3. 第一次选择素材库

1. 点击工具栏上的灵感采集图标。
2. 按首次使用提示进入设置；也可以点击弹窗右上角的齿轮。
3. 在 **素材库位置**中使用推荐位置，或点击 **更改素材库**，通过系统文件夹窗口选择位置。
4. 确认后，以后的新任务默认保存到这里。

选择一个空间充足、准备长期保留的文件夹即可。下方的“灵感素材库”是结构示例，名称和位置由你决定。

素材会按“功能 → 平台”整理：

```text
灵感素材库/
├─ 图片/小红书/作品标题/
├─ 图文/小红书/作品标题/
├─ 视频/小红书/作品标题/
└─ 批量/小红书/作者或画板/
```

以上为示例。平台名称和作品目录会随采集内容变化；批量同一作者或画板的内容放在一起，不再按图片、图文、视频拆开。

**更改默认素材库只影响以后的新任务，不会搬迁旧文件。** 历史记录和继续执行的旧任务仍沿用原保存位置。

### 只想这一次存到别处？

在采集弹窗底部的 **本次保存到** 卡片中：

- **选择…**：打开系统目录窗口，为本次任务选择其他位置，不改变长期素材库。所选位置下仍会按功能和平台分类。
- **恢复默认位置**：取消临时位置，重新使用素材库。
- **打开文件夹**：打开本次对应的功能／平台目录；目录尚未创建时，需要先完成一次采集。

普通采集偏好会沿用，临时保存位置不会作为下次的长期默认值。

## 4. 保存当前作品

先在 Chrome 登录目标平台，打开具体作品页面，再点击扩展。

| 想保存什么 | 怎么选择 |
| --- | --- |
| 作品图片 | **当前作品 → 采集内容：图片** |
| 正文和图片整理成笔记 | **当前作品 → 采集内容：图文笔记** |
| 只保存文字，不要图片视频 | **当前作品 → 采集内容：纯文字 · Markdown** |
| 视频文件 | **当前作品 → 采集内容：视频 → 仅保存** |
| 视频文件和提取的画面 | **当前作品 → 采集内容：视频 → 保存并抽帧** |

选择好后检查保存位置，点击底部主按钮。视频会先检查或估算大小，再由你确认下载；显示“等待下载确认”时，按提示确认后继续。

纯文字模式只输出 `.md`，不下载图片、视频或执行 OCR。前台的 **附带已加载评论** 默认关闭，可按需勾选并沿用。正文为空会提示失败，不生成空笔记；评论仅包含当前平台能识别的已加载部分。应用内部保留去重索引，笔记目录不放 JSON。纯文字使用带“纯文字”标识的独立作品／批量目录，不继承或删除旧图文附件。若手动修改过 MD，再次采集会另存，保留你的修改。

### B站视频

当前视频：打开具体 BV 稿件，选择 **视频 → 仅保存／保存并抽帧**，也可选择 **音频** 单独保存 M4A。

0.5.28 会在缺少页面播放身份等特定情况下尝试内置 yt-dlp B站提取器，仍绑定指定 BV 与 `p`；不会因为页面右侧存在合集就展开整套合集。明确错稿件、受保护或试看不会启用这一回退。

批量：打开 UP 主空间的 **投稿 → 视频** 列表，选择 **批量采集 → 视频**，填写视频数量；可选择保存并抽帧。每个投稿默认处理第一 P；要保存其他分 P，请打开对应的单视频地址（带 `p` 参数）再采集。

只读取与当前稿件和 UP 主匹配的内容，跳过广告及推荐卡片；不自动删除视频画面里的口播或植入广告。优先选择兼容 AVC/AAC 清晰度，分轨会在本地合并；缺音轨、试看、未知格式或页面结构不匹配时会报错。可选画质取决于来源，程序不绕过登录或付费限制。B站不提供直接从网页播放器“仅抽帧”，请使用保存并抽帧。

Windows 包内置本地媒体组件，不需要另外安装。B站页面结构与视频格式可能影响采集；Reddit 尚未接入。

图文笔记保存为 Markdown 文件，可用文本编辑器或支持 Markdown 的笔记软件打开。图文选项中：

- **正文图片**：同时保存正文里的图片。
- **评论**：保存页面已经加载、程序能够识别的评论。
- **图片文字识别**：使用本机 OCR 提取图片文字，结果可能需要人工校对。

图片／图文模式中的 **附带视频**决定遇到视频时如何处理。选择独立的视频模式后，使用“仅保存／保存并抽帧”，不需要再配置附带视频。

重复采集通常保留 **自动去重补齐** 即可：检查本地文件，补齐缺失内容，避免相同内容反复保存。**重新读取原帖**会更新来源内容，复用原目录，并保留手动编辑内容。

## 5. 批量采集

1. 打开作者主页，或 Pinterest 的具体画板，而不是搜索结果或推荐首页。
2. 打开扩展，切换到 **批量采集**。
3. 选择图片、图文笔记或视频，设置本次数量。
4. 检查保存位置，点击开始；视频任务还需要确认下载。

**批量视频**：选择“视频 → 仅保存”。

**批量视频抽帧**：选择“视频 → 保存并抽帧”。

这两种视频任务只处理视频，图片帖会跳过，不占视频额度。一篇帖子里有多个视频时，按视频数量计算；重复或失败的视频也会占本次额度，例如设为 10 时，新增文件可能少于 10 个。一次任务最多扫描 500 篇帖子，可能在找到足量视频前到达扫描上限。

采集期间请保持桌面程序运行，保留目标网页，不要切换它的地址。首次使用建议先试 2–3 篇，确认结果符合预期后再增加数量。

### 平台有什么区别？

| 平台 | 适合从哪里开始 |
| --- | --- |
| 小红书 | 单篇笔记或作者主页；支持图片、图文及视频相关模式 |
| X | 单帖或作者主页；批量按页面顺序采集本人帖子，不包含转帖 |
| Instagram | 单帖、作者帖子列表或 Reels 列表 |
| Pinterest | 当前 Pin 或具体画板；批量图文模式不提供 |
| 花瓣 | 当前采集及批量图片 |
| 其他网页 | 以当前页面图片采集为主，不提供通用批量能力 |

页面结构、登录状态及视频格式会影响结果。先选择弹窗里可用的功能；遇到失败时，可按错误提示检查页面和媒体格式。

## 6. 查看结果、继续任务与重试

点击弹窗齿轮，进入管理页，再点击 **记录**。

### 采集记录

已保存的作品集中在这里。可以组合使用：

- 关键词：标题、作者或原链接；
- 分类：图片、图文、视频、批量；
- 平台：小红书、X、Instagram 等。

输入关键词后点击 **查询**。找到作品后可打开保存文件夹或原帖。记录保留实际保存位置；手动移动文件后，记录不会自动跟着更新。

旧素材未出现在记录中时，可展开 **导入或重新关联旧采集目录**，填写原目录，先预览再确认；这不会搬动素材。

### 待处理

这里只显示正在运行、未完成或有失败的任务，不重复列出全部成功任务。

- **回原页续采**：恢复未完成任务，回到原网页，再打开扩展确认继续。
- **只重试失败项**：只针对失败或部分失败的项恢复任务。
- 部分失败任务中已经成功的作品，仍可在采集记录里找到。

**“卡住时停止并重置”**用于停止当前任务、清理残留状态。想接着采集，请使用“回原页续采”。若重置后仍卡住，记录错误提示，再检查目标网页和后台连接。

## 7. 更新与卸载

### 更新：每次安装新版本前，先退出旧版后台

**最重要的一步：先退出「灵感采集」后台，再打开新的安装包。** 仅关闭 Chrome、扩展弹窗、网页、说明书或 Chrome 扩展管理页，都**不会**退出后台程序。旧后台继续运行时，Windows 安装器可能反复提醒程序没有关闭、无法继续覆盖安装。

1. **完成或停止正在运行的采集任务。** 如果正在批量采集，先在扩展里停止或等待本轮结束，避免中途打断保存。
2. **找到托盘图标。** 看 Windows 任务栏右下角的通知区域。没有看到「灵感采集」，点击向上的小箭头 **∧** 展开隐藏图标，再把鼠标停在图标上确认名称。
3. **真正退出旧程序。** 在「灵感采集」图标上单击鼠标右键，选择 **退出灵感采集**。稍等片刻，确认图标消失。旧版 0.5.11 及更早版本若仍有“灵感采集已启动”的独立窗口，请按该版本的退出方式关闭它。
4. **再运行新版安装包。** 从 [GitHub Releases](https://github.com/iiiiivy123/inspiration-collector/releases) 下载新的 Windows x64 `Setup.exe`，安装到**上次安装的位置**。通常**不必先卸载旧版本**，也不要删除你自己选择的素材库、历史记录或本地配置。
5. **确认本地后台已启动。** 安装向导可能在结束时启动程序；如果托盘里没有「灵感采集」，再从桌面或开始菜单启动一次。
6. **重新加载 Chrome 扩展。** 在 Chrome 地址栏输入 `chrome://extensions`，找到「灵感采集」扩展卡片，点击 **重新加载**（Reload）。已经打开的目标网页也请刷新一次，再打开扩展采集。

**如果安装器仍提示“灵感采集没有退出 / 程序正在运行”：** 先取消或关闭本次安装向导，重新检查右下角隐藏的托盘图标，选择 **退出灵感采集**，不要反复点击安装。如果图标不见了却仍报错，可以打开 Windows 任务管理器，核实是否仍有本软件的 `InspirationCollector.exe` 进程；**仅在确认进程属于本软件时**再考虑结束它。无法确定时可重启 Windows，且不要先启动旧版，之后重新执行安装。不要结束名称不明的进程。

**更新后文件在哪里？** 正常覆盖安装不会主动移动或删除你选定的素材库；历史记录仍指向原来的位置。更改保存路径也不会自动迁移旧文件。当前版本**没有自动更新**，每次获取新版本都需要手动完成上述步骤。

### 卸载

先停止任务并退出桌面程序，再从 Windows 的“已安装的应用”中卸载；Chrome 中的扩展需要另外移除。

卸载不会删除你选定的素材库，也不会删除独立保存的偏好和采集索引。如需彻底清理，请在确认备份后另行处理这些数据。

## 8. 常见问题

**扩展提示连接不上服务？**

先从开始菜单或桌面快捷方式打开灵感采集，查看右下角托盘图标。如果提示端口被占用，按上面的更新步骤退出旧版程序；不要随意结束不认识的进程。重复双击不会启动第二份后台。程序不默认开机自启，重启电脑后需启动一次；日常无需一直打开说明窗口。

**“加载已解压的扩展程序”失败？**

检查是否选中了安装目录中的 `extension` 文件夹，其中应有 `manifest.json`。不要选择安装包文件、源码 ZIP 或上一级目录。

**批量采集不能点？**

检查当前平台是否支持该模式，并先打开对应作者主页或具体画板。换到支持的内容类型后再试。

**视频没有立即开始下载？**

检查是否正在等待下载确认。大小未知时，请先确认磁盘有足够空间；抽帧还会额外生成图片。受保护或无法解析的视频可能不能下载。

**选择文件夹后弹窗关闭了？**

系统目录窗口可能使 Chrome 弹窗失去焦点。完成选择后重新打开扩展，检查“本次保存到”；取消选择不应改变原位置。

**图片文字识别不可用或不准确？**

OCR 依赖 Windows 本机识别组件和语言支持。可以先关闭图片文字识别保存其他内容；保存后请校对识别结果。

**明明采集成功，打开文件夹却找不到想看的文件？**

弹窗打开的是当前任务对应的目录。找以前的作品，请去采集记录中打开那条作品的文件夹；旧任务可能保存在之前的素材库位置。

**还没解决？**

向维护者提供扩展版本、平台、操作步骤和错误提示截图。提交反馈前请遮住个人路径、私密内容和账号信息，不要发送 Cookie、登录凭据或完整个人配置。

## 使用范围

## 0.5.41 新增入口

- 当前页预扫描和正式保存共用提取流程。更多选项中的“向下加载并扫描”会向下加载最多 12 屏，汇总当前作品的正文和媒体，显示停止原因。扫描内容在同一标签页保留 5 分钟，用于随后保存。更换页面或过期后重新识别。
- 通用网页需有明确文章正文。菜单、侧栏和已识别的推荐区会被过滤；多篇文章列表或无法定位正文时会给出提示。
- ArtStation 支持作品媒体区的普通 MP4/WebM 和 YouTube 嵌入视频。开启“包含视频”后可顺序保存；其他嵌入播放器、3D模型和附件仍待接入。
- 本地 GIF／音频加工显示转换进度，支持按任务停止。
- MCP 的 reftray_download_videos 接收原帖链接，把原帖全部视频顺序下载，返回 job_id 和 kind=task。reftray_job_status 查询每个视频的结果，reftray_stop_queue 停止指定队列。原有 reftray_download_video 仍可按 media_index 单独选一个。
- MCP 的 reftray_capture_browser 接收 url 和 mode（images、text、video）。请在 Chrome 打开该链接，保持灵感采集弹窗打开；扩展会接收请求并用该页面采集，结果用 kind=task 查询。登录状态留在浏览器里。相同网址有多个标签时，请保留一个。新版扩展和后台须为同一版本。
- Chrome 连接只在采集弹窗打开期间检查请求。等待接收超过 5 分钟会记为失败；后台重启后的未完成任务显示已中断，已保存文件保留。
