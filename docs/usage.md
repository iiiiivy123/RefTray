# RefTray 0.5.48 使用教程

适用于 Windows + Chrome。首次使用见 [安装步骤](install.md)，从旧版升级见 [更新步骤](update.md)。

## 当前作品怎么保存

打开作品详情页，点 Chrome 工具栏里的 RefTray，选择采集内容和保存位置。

| 采集内容 | 保存什么 | 常用选项 |
| --- | --- | --- |
| 图片 / GIF | 图片与动图 | 跳过视频、跳过 GIF |
| 图文笔记 | 正文 Markdown 和正文图片 | 媒体过滤、附带评论、识别图片文字 |
| 纯文字 · Markdown | 正文文字 | 附带评论 |
| 视频 | 视频、字幕文字稿或音频 | 保存内容、画质、自动抽帧、跳过开头 / 结尾 |

图片和图文默认跳过视频。图文自带正文图片；只需要文字时选纯文字。图片文字识别用于把图中的文字补进图文笔记。

## 视频、字幕、MD 和音频

「保存内容」有四种选择：

- **视频 + 字幕 + MD**：保存视频，并提取网站提供的字幕和文字稿。
- **仅视频，不提取文字**：只保存视频。
- **仅文字稿（MD）**：保存文字稿。
- **仅提取音频**：保存音频。

没有字幕的视频暂时不会自动语音转写。「自动抽帧」另行开启，默认每 1 秒一张，间隔在设置页修改。「跳过开头 / 结尾」填写秒数。

本地视频可以在管理页工具中抽帧、转 GIF 或提取 M4A 音频，结果另存。

## 评论怎么计数

勾选「附带评论」，再设置最多一级评论数，默认 10 条。楼中楼默认关闭；开启后，每条一级评论默认最多保存 2 条回复，不占一级评论名额。小红书和 Instagram 显示楼中楼选项，折叠回复仍需在网页展开。

## 批量采集

打开作者主页、画板或视频列表，切到「批量采集」，选择内容类型、数量和保存位置。可以设置跳过前几篇。

X 图片批量会跳过没有所选媒体的作品，再继续后面的帖子；这项新规则仍需原主页复测。已保存内容按设置中的去重方式处理。任务详情分别列出新增、已有、跳过和失败结果。

进度圆圈显示整批进度，旁边显示当前作品的处理情况。解析和扫描时显示当前阶段；等待下载确认时先确认，再继续保存。

## 设置页放哪些参数

| 设置 | 用途 |
| --- | --- |
| 自动去重补齐 / 重新读取原帖 | 再次采集同一作品时的处理方式 |
| 下载上限 | 限制单个媒体的下载大小 |
| 默认一级评论数 | 每篇作品默认收集多少条直接评论 |
| 每条一级评论最多回复数 | 楼中楼开启后的每层回复数量，默认 2 条 |
| 最小图片宽度 | 过滤低于指定宽度的小图，单位是像素 |
| 抽帧间隔 | 两张参考画面之间的时间，默认 1 秒 |

## 找文件、重试和查原因

完成后点「打开保存位置」。采集记录保留作品和文件位置；更改素材库位置不会搬迁旧文件。

失败时打开任务详情，选择只重试失败项。带诊断编号的错误可以直接跳到对应诊断，也可以在诊断页搜索编号、站点或错误文字。
