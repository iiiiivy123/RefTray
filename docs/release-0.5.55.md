# RefTray 0.5.55 · 正式版

RefTray 是 Windows + Chrome 本地素材采集工具：把网页里的图片、图文、视频和音频保存到自己的文件夹，也可以通过 MCP 交给 AI 操作。

## 下载与安装

Windows 10/11 64 位用户请下载 `InspirationCollector-0.5.55-Windows-x64-Setup.exe`。`SHA256SUMS-0.5.55.txt` 用于核对文件；`user.zip` 是源码运行包，需要自行准备 Python 环境。

安装后从托盘复制扩展目录，在 Chrome 扩展管理页加载该目录。旧用户覆盖安装后重新加载扩展，并刷新作品页；MCP 客户端需要时重新连接。素材、设置和采集记录保留。

## 这一版包含什么

- 图片/GIF、图文 Markdown、纯文字、视频/字幕/文字稿/音频采集。
- 小红书收藏夹、花瓣/Pinterest 画板、X 作者主页、B站分 P/合集等批量入口，支持起点与数量。
- 本地字幕识别、视频抽帧、转 GIF、提取音频。
- 采集记录缩略图、具体内容类型，以及任务暂停、继续和失败重试。
- MCP 与扩展共用采集流程，一键更新与上一版程序恢复。

本次冻结现有功能与界面。正式发布只整理下载入口和随包说明。

## 使用范围

需要登录的网页使用已登录的 Chrome。X 作者主页批量采集时请保持页面在前台。评论、折叠回复和视频能否取得受具体平台及页面加载情况影响；不提供付费、DRM 或访问限制的绕过功能。旧音频记录没有封面时显示音频标记。
