# RefTray 1.0.0 · 正式版

RefTray 把网页里的图片、图文、视频和音频保存到你选的文件夹。它由 Windows 后台和 Chrome 扩展组成，也可以通过 MCP 让 AI 提交采集任务。

**1.0 与 0.5.55 的功能、界面相同。** 这次统一正式版编号和发布文件，已有素材、设置和采集记录保留。

## 下载和开始使用

Windows 10/11 64 位、Chrome 120 或更新版本，请从[本次发布](https://github.com/iiiiivy123/RefTray/releases/tag/v1.0.0)下载 `InspirationCollector-1.0.0-Windows-x64-Setup.exe`。

安装包内置运行环境和媒体组件。`user.zip` 是供自行配置 Python 的用户使用的源码包，不能当免安装版直接打开。

1. 安装并启动“灵感采集”。
2. 从托盘复制扩展文件夹地址，在 `chrome://extensions` 加载该文件夹。
3. 打开作品页，选择素材库和采集内容，开始保存。

旧用户覆盖安装后重新加载扩展、刷新作品页；使用 MCP 时，在 AI 客户端重新连接。安装包暂未签名，下载后按[安装教程](install.md)核对 SHA256。

## 这一版能做什么

- 保存图片、GIF、图文 Markdown、纯文字、视频、字幕和音频。
- 批量采集支持的作者主页、画板、收藏夹、B站分 P 和合集。
- 在本机识别字幕、抽帧、转 GIF 和提取音频。
- 查看带缩略图的采集记录，暂停、继续任务或重试失败项。
- 通过 MCP 调用采集功能，检查更新和恢复上一版程序。

## 使用时留意

需要登录的网页先在 Chrome 登录。X 作者主页批量期间保持该页面在前台。评论和折叠回复依赖页面加载情况，保存后可与原页核对。旧音频记录没有封面时显示音频标记。

保存素材时留好原链接、作者、标题和权利说明。转载、公开分享或商用前，确认授权覆盖这次用途；没有许可时先联系权利人。RefTray 不绕过登录、付费、DRM 或访问限制。[素材使用与隐私](rights-and-privacy.md)
