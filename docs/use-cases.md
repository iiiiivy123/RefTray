# 常见问题

适用于 RefTray 1.0。首次使用先看[安装步骤](install.md)，具体操作看[使用教程](usage.md)。

## 安装后没有主窗口，正常吗？

正常。后台在 Windows 右下角托盘运行，采集和设置在 Chrome 扩展里。打开工具栏里的“灵感采集”即可；第一次还需要[手动加载扩展](install.md)。

## 提示“服务启动失败”或“连接不到后台”

先从开始菜单启动“灵感采集”，确认托盘图标出现，再重新打开扩展。升级后才出现的问题，可按[更新与恢复](update.md)尝试恢复上一版程序。

先保留素材库和任务数据库。启动日志默认在 `%LOCALAPPDATA%\InspirationCollector\data\inspiration\logs\service-errors.log`；使用自定义状态目录时，日志在该目录的 `data/inspiration/logs/` 下。反馈报错时间、版本和相关错误片段即可。

## 安装完成了，扩展怎么还是旧版？

打开 `chrome://extensions`，找到“灵感采集”，点击重新加载，再刷新作品页。若版本仍旧，检查扩展加载的文件夹是否与托盘复制出的地址一致。[完整更新步骤](update.md)

## 安装卡在“Preparing to Install”

这个阶段正在等旧后台退出、处理 MCP 占用并准备程序备份。先完成或停止采集任务。若安装失败，保留安装日志和原程序目录，按报错处理；删目录重装可能把恢复文件一起删掉。

## 为什么没有提醒我更新到预发布版？

更新检查只看正式版。到 **设置 → 关于与更新** 点击“检查更新”，再选择“下载并更新”。程序会提醒新版，但不会替你定时安装。预发布版需到 Releases 手动下载。

## 花瓣图片已经显示，为什么还说没找到正文图片？

先进入作品详情页，等主图加载完成，再开始采集。画板批量请打开具体画板。若图片可见但仍失败，保留作品链接、当前页面截图和任务中的诊断编号，方便定位是哪种页面。

## X 网页能播放，保存却提示“主帖身份字段缺失”

这表示采集时没有取得当前帖子的必要媒体信息。先打开帖子的详情页，确认媒体加载完成；更新过扩展的话，再刷新一次网页。仍失败时提供诊断编号和页面链接，不需要提供登录信息。

## X 批量中途停了，或者保存数量比填写的少

采集期间保持作者主页在前台，不要切换列表或排序。切到其他标签后程序会等待；等待超过约 30 秒会留下已完成结果，回到主页后再继续未完成任务。

没有所选媒体的帖子、转帖和引用帖会被跳过。打开任务详情，分别看新增、已有、跳过和失败项；“想取几篇”和“新下载几篇”不一定相同。

## GIF 应该从哪里保存？

选“图片 / GIF”，并确认没有勾选“跳过 GIF”。保存完成后打开文件检查是否能播放。图文采集里的主帖 GIF 和评论配图放在图文作品目录；单独采图片时放在图片目录。

如果小红书动图旁多出 JPG，先核对本次新建文件，确认它是正文配图还是重复封面。这类反馈仍需要具体页面和结果文件来核对；旧文件不会自动清理。

## 评论数量包不包含楼中楼？

“最多一级评论数”只算直接评论。楼中楼默认关闭，开启后每条一级评论默认最多保存 2 条回复，另行计数。数量在设置页修改，弹窗里选择是否采集评论。

小红书和 Instagram 会尝试展开所选评论的回复。页面未加载、折叠、访问受限或等待超时，都可能让结果少于设定数量；需要完整记录时，请对照原页面检查。

## B站各种保存方式都显示 Not Found

先核对后台和扩展版本是否一致。旧后台仍在运行时，新扩展可能找不到对应功能；退出自己的旧后台，启动当前安装版，再重新加载扩展。仍有问题时，把诊断中的请求路径和错误提示一起反馈。

## 文件去哪了？怎么找失败原因？

在采集记录中找到作品，点击“打开保存位置”。图文的图片、GIF 和 Markdown 在同一作品目录；旧版本保存的文件仍在原位置。更改素材库路径只影响后续任务，不搬旧文件。

失败项可从任务详情跳到对应诊断，也可以在左侧“诊断记录”按编号、站点或错误文字搜索，再展开“查看详细日志”。

## 升级后 AI 提示 Transport closed

升级会关闭旧的 RefTray MCP 进程。启动新版后台后，在 AI 客户端重新连接 RefTray，再调用 `reftray_status` 查看版本。连接配置一般不需要重填。[MCP 接入](mcp.md)

## 保存的素材能直接转载或商用吗？

先确认作品授权是否覆盖这次用途。保留原链接、作者、标题和权利说明；没有转载或商用许可时，先联系权利人。署名、个人收藏或“不赚钱”都不是通用授权。[素材使用与隐私](rights-and-privacy.md)

反馈问题时附版本、步骤和必要的截图，先遮住私人信息；不要提交 Cookie、密码或完整私人日志。
