# RefTray 0.5.50 · 1.0收尾候选

本版补齐批量范围、连接提示、更新恢复及采集收尾功能。正式发布由验收后的发布操作决定。

- B站直接填写“从第几P开始”，显示预计范围；原MCP参数与续采断点继续兼容。
- 更新前保存完整旧程序；新版安装或启动失败自动恢复。更新成功后也可从管理页或MCP恢复上一版，保留现在的素材、设置和采集记录。后台打不开时使用状态目录中的独立恢复程序。
- 更新页显示后台与扩展版本、恢复位置，说明Chrome重载及AI重新连接；MCP随完整包升级，原配置不变。
- 无网站字幕时使用随包本地CPU语音识别，输出字幕及文字稿；网站原字幕优先，视频不删除。
- 小红书/Instagram楼中楼按数量有界展开；未加载足够回复时说明原因。
- B站同一轨道提供备用线路时，传输中断会换线路重新下载当前轨道；停止、大小限制和内容异常继续生效。
- 页面读取、批量计数、媒体传输和程序恢复各自分离，保留原平台入口、任务格式与目录规则。

更新与恢复操作见[更新说明](update.md)，范围和评论操作见[使用教程](usage.md)，AI入口见[MCP说明](mcp.md)。ArtStation交互3D与特殊附件继续后置。
