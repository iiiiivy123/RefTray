# RefTray 1.0.1 发布检查

## 本次改动

更新器兼容 RefTray 和 inspiration-collector 两个官方仓库名，只有新地址返回 404 时才尝试旧地址。安装包名称、长度和 SHA256 校验、忙碌检查及恢复流程保持。新增公开 B 站测试样本，让干净检出也能运行完整回归。用户教程和素材版权说明同步整理。

真实旧版清单检查发现升级预检遗漏 help 与 speech-tools 目录，已在 `924eb3d` 补齐这两个已发布目录。新增回归覆盖允许目录、用户修改保留、未知目录和路径越界拒绝。修复前真实清单失败，修复后通过。
