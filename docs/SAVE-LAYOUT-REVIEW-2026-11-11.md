# 保存目录变更记录（0.5.52）

这份历史记录保留旧版与新版目录的对照。日常使用请看[素材保存目录](save-layout.md)，不需要逐列比较旧规则。

右栏用于 0.5.52 起的新采集；左栏保留旧规则供比较。下文路径均从用户选择的素材库根目录开始。标题撞名时可能追加短编号；每个目录中的 `_来源记录` 用来记录来源和去重，表格省略它。

**新任务使用右栏结构，旧素材不搬动，旧任务续采保留原位置。** “内容”指实际文件，不会创建名为“内容”的文件夹。只创建本次用到的目录；失败不保留本次新建且仍为空的目录，不自动清理用户已有目录。首次重新采集旧作品可能新增一份新结构的副本，新结构内重采复用原目录。

## B站

视频文件、字幕和文字稿放在同一个作品目录；“仅音频”使用 `音频-标题`，文件是 `.m4a`。单篇图文与专栏已有入口：打开具体 `/opus/…` 或 `/read/cv…` 页面选图文，上一版表格漏列了这一项。

以下树为旧规则参考：

```text
视频/B站/
└─ 视频标题/
   ├─ 视频标题_短编号.mp4
   ├─ 同名.srt            （选了视频+字幕+MD时）
   └─ 同名.md

批量/B站/
└─ UP主/
   ├─ 视频/              （UP主投稿列表，视频直接放这里）
   └─ 合集名或分P总标题/
      └─ 视频/           （各稿件/各P文件直接放这里）
```

旧规则从素材库算，单视频是“视频 → B站 → 标题”3层；UP主视频批量4层；合集/分P批量5层。分P文件名保留 P 序号及分P标题；多稿件合集保留各稿件标题。

| 入口 | 旧规则 | 新采集规则 |
|---|---|---|
| 单篇图文 / 专栏 | `图文/B站/标题/内容` | `图文/B站/图文-标题/内容` |
| 单视频 | `视频/B站/视频标题/内容` | `视频/B站/视频-标题/内容` |
| 分P | `批量/B站/UP主/总标题/视频/各P文件` | `批量/B站/分P采集-总标题-UP主/P03-分P标题/内容` |
| 多稿件合集 | `批量/B站/UP主/合集名/视频/各视频文件` | `批量/B站/合集采集-合集名-UP主/视频-稿件标题/内容` |
| UP主投稿 | `批量/B站/UP主/视频/各视频文件` | `批量/B站/主页采集-UP主/视频-稿件标题/内容` |
| UP主图文 | `批量/B站/UP主/图文/作品标题/内容` | `批量/B站/主页采集-UP主/图文-作品标题/内容` |

## 微博、其他网页

当前只提供单页入口：`图片或图文/微博或其他网页/图片或图文-页面标题/内容`。这里没有新增批量入口。

## 两个共通例外

- **纯文字**：单篇直接放 `图文/平台/文字-标题_短编号.md`，批量直接放相应采集分组中，不另开作品/附件目录。视频的“仅文字稿”会生成 SRT 和 MD，两份文件放在 `图文/平台/文字-标题/`。
- **省掉平台层**：设置中的另一种布局会让单篇直接成为 `图片或图文或视频/平台-类型-标题/内容`，既有作品仍复用原目录；上述表格使用默认的“功能 → 平台”布局。

批量每篇按实际所选模式使用“图片 / 图文 / 视频 / 音频”前缀；分P固定为“P03-分P标题”。默认单篇3层、批量4层；图片平铺和纯文字例外更少。旧文件不迁移、默认素材库设置不改变。
