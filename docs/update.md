# 旧版更新：先退出后台，再安装，最后重载扩展

适用于 Windows 安装版。来自开发目录、历史源码包或不同位置的后台，请先看最后一节，避免两个后台争用端口。

## 更新步骤

1. **完成或停止当前任务。** 不要在下载、合并、抽帧或写入图文时强制结束进程。
2. **退出旧后台。** Windows 右下角托盘图标右键 →「退出灵感采集」。如果图标收起了，点向上的小箭头查找。关闭扩展弹窗、Chrome 或设置页后，后台仍会运行。
3. **保留原安装位置，运行新版安装包。** 到 [Releases](https://github.com/iiiiivy123/inspiration-collector/releases) 下载 `InspirationCollector-版本-Windows-x64-Setup.exe`，按向导覆盖原安装版。不要先删除素材库或程序状态目录。
4. **启动新版后台。** 从开始菜单或桌面快捷方式打开「灵感采集」。
5. **重载 Chrome 扩展。** 打开 `chrome://extensions`，找到「灵感采集」，点击「重新加载」（圆形箭头）。若扩展不在当前安装目录，用托盘菜单找到新的 extension 文件夹，重新加载对应文件夹；不要保留两份同名扩展同时工作。
6. **刷新作品网页。** 已打开的网页和播放器仍可能留着旧内容脚本。刷新后重新打开扩展，确认版本与后台一致、显示「后台已连接」，再做一项普通素材保存测试。

7. **刷新AI客户端的MCP连接。** 使用接口的用户在新版后台启动后重新连接即可。启动路径和工具参数见 [MCP接入说明](mcp.md)。

## 哪些数据应当保留

- **素材文件**：在你自己选择的素材库目录，更新不自动搬迁、不删除、不覆盖手动修改的 Markdown。
- **安装版状态**：默认在 `%LOCALAPPDATA%\InspirationCollector\data\inspiration`，包括素材库设置、索引与历史记录。
- **扩展偏好**：保留同一个已加载扩展时，Chrome 自己保存其偏好；删除扩展再安装可能丢失浏览器侧偏好。

更新前请备份重要资料。安装器只更新程序文件；已损坏或已删除的数据需要从备份恢复。

## 出现问题时

- **提示程序仍在运行**：退出安装向导，确认旧托盘后台已退出后再装。不要强行覆盖运行中的程序。
- **扩展版本与后台不一致**：检查扩展详细信息中的加载路径，重载后再刷新网页；只更新其中一端不够。
- **端口已占用**：确认旧开发版、另一安装位置或旧开机启动项是否仍运行。不要结束来源不明的其他程序。
- **回退上一版**：先停止任务并退出新版后台，再安装旧版并重载对应扩展。请单独保留更新前的状态备份；旧版可能无法读取新版数据库，回退前先确认版本兼容性。

## 从源码版或其他目录切换到安装版

先退出旧目录中的后台，并检查自己设置的开机启动项，避免同时运行两份服务。原目录可以保留，无需先删除。

源码版的设置和历史记录位置取决于原来的启动配置。安装前记下素材库地址，安装后重新选择；文件会留在原处。需要迁移历史记录时，先备份，再请维护者核对。扩展文件夹请从新程序的托盘菜单复制，使用这台电脑上的实际地址。

没有自动更新。新版本以 GitHub Release 为准，首次安装见 [安装教程](https://github.com/iiiiivy123/inspiration-collector/blob/main/docs/install.md)。

0.5.39 候选会核对扩展目录。若升级后旧弹窗提示连接失败，从托盘打开已登记的扩展目录，在扩展管理页重载该目录的扩展，再刷新作品页。安装同步按清单处理程序文件，保留无归属证据或内容已修改的旧文件。
