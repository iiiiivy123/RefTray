0.5.28测试发布已清理，本文保留为历史更新记录。请在 [最新下载页](https://github.com/iiiiivy123/RefTray/releases/latest) 获取当前Windows安装包和SHA256校验文件。

## 这次改了什么

- **B站下载**：缺少页面播放信息时，尝试用内置 yt-dlp 提取器继续解析。只处理指定 BV 和分P，不展开整套合集；稿件不匹配、受保护或试看内容仍会停止。
- **B站音频**：可以单独保存为 M4A，优先保留 AAC 音轨；视频优先选择兼容的 AVC/AAC 格式，减少额外转码需求。
- **公开 HLS 视频**：修复音轨缺少格式标记时被丢弃的问题。H.264/AAC 分段使用内置组件合并为 MP4。
- **图片和图文**：按篇保存，不再等待整批视频预处理。正文和图片先落盘，附件失败时标为“部分完成”。
- **下载设置**：移除主动磁盘空间预估与预留拦截，保留下载大小上限、取消、来源安全和文件完整性检查。
- **批量采集**：增加跳过前若干篇、时长范围和 MB/GB 下载上限选项。
- **图标**：扩展、Windows 程序和安装器统一使用 RefTray 简洁文件图标；托盘有深浅两种对比版本。
- **Windows 启动**：增加版本核对，避免 localhost 代理干扰；错误日志经过脱敏并限制数量。沿用旧安装标识和独立数据目录。
- **组件说明**：安装包附带 CAT·LOGUE、yt-dlp、Python、FFmpeg 和依赖的许可材料，以及 FFmpeg 对应源码和重建说明。

## 已知问题和还没测到的部分

- **X 扩展采集仍需复测**：测试环境无法打开 X 网页。本次只测通了上表中的后台下载样本；此前失败的原链接和浏览器扩展流程尚未完成复测。
- **其他平台没有逐一重新测试**：小红书、Instagram、Pinterest、花瓣、YouTube 等页面可能仍受改版、登录、地区、权限或媒体格式影响。
- **部分功能需要额外组件**：语音识别模型、完整转码／GIF 组件，以及 YouTube 可能需要的 JavaScript 运行组件未全部内置。缺少组件时，相关步骤会失败或显示部分完成；视频和字幕请分别查看结果。
