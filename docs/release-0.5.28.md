# 0.5.28 · 朋友试用版

> 已有旧版时，**先在 Windows 托盘右键 → 退出灵感采集**，再安装新版；安装后到 `chrome://extensions` 重新加载扩展，并刷新作品网页。关闭 Chrome 不等于退出后台。

## 下载与使用

下载本 Release 的 **`InspirationCollector-0.5.28-Windows-x64-Setup.exe`**，不要把 Source code ZIP 当成安装包。

- [首次安装](install.md)
- [旧版更新与数据保留](update.md)
- [完整使用教程](usage.md)

Windows 10/11 64 位 + Chrome；安装包内置 Python、依赖、yt-dlp 与基础媒体检查／合并组件。程序以托盘后台运行，没有新增另一套桌面设置软件，没有自动更新或默认新增开机启动。尚未代码签名，请核实来源，不要关闭安全防护。

## 本次变化

- B站缺少页面播放身份等特定情况可使用 yt-dlp 的 B站提取器回退，固定为请求的 BV 与分P，不展开整套合集。明确错稿件、受保护或试看仍拒绝。
- B站音频可独立下载；优先 AAC 无损保存。视频优先兼容 AVC/AAC，减少对额外转码组件的依赖。
- 修复公开 HLS 来源中“选出的音轨未标 acodec 就被丢弃”的问题；兼容 H.264/AAC 的分段结果使用内置组件可处理的 MP4 合并，不再强制使用未随基础组件提供的 Matroska 封装器。
- 图片／图文按篇保存，不再等整批视频统一预处理；正文和图片先保存，附件失败记录部分完成。
- 取消主动磁盘空间探测与预留拦截，保留下载字节上限、取消、来源安全与完整性检查。
- 批量增加跳过前若干篇、时长范围及下载 MB/GB 选项；弹窗保留原有实际处理控件。
- 使用已确认的 **RefTray A**：空白文件轮廓＋右上方块。替换扩展、程序和安装器图标，托盘提供深浅对比版本。
- Windows 托盘启动增加版本核对、绕过 localhost 代理、限量脱敏错误日志；保留旧版安装标识与独立数据目录。
- 安装包包含 CAT·LOGUE、yt-dlp、Python、FFmpeg 及依赖的相关许可材料；FFmpeg 包含对应源码和重建说明。

## 仍需说明的限制

- B站扩展验收用独立、未登录的真实 Chromium 环境；并非用户原有已登录窗口的操作录屏。旧窗口仍需重载扩展、刷新作品页。
- X 网页在独立测试环境访问失败；本轮只完成普通公开样本的后台全链路验证，**没有完成原失败链接或 X 浏览器扩展全链路验收**。
- 本轮不逐站保证小红书、Instagram、Pinterest、花瓣、YouTube 等所有页面均重新实测通过。页面改版、登录、地区、权限和媒体格式仍会影响结果。
